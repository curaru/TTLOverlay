# TTLOverlay

TTLのギフトカタログを常に最新の状態で取得し、選択したギフトをトリガーとし、それに対する任意のサウンドやグラフィックを設定することでリアルタイムに配信画面に反映。

配信者ごとの演出を手軽に組み合わせられる、シンプルで拡張しやすいオーバーレイを目指しています。

## 主な機能（予定）
- **ギフトカタログの自動同期**: 最新のTTLギフト情報を自動取得
- **トリガー設定**: ギフトイベントに応じた演出（サウンド・画像・アニメーション）の割り当て
- **OBS / 配信ツール連携**: ブラウザソースとして埋め込み可能なオーバーレイ画面の提供
